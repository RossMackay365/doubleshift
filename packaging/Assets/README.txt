DoubleShift icon and Store assets
=================================

packaging/Assets/  The 20 app icon PNGs for the package manifest (sRGB, transparent), flat,
                   named exactly as in the brief.
DoubleShift.ico    Program file and window icon
                   (16, 20, 24, 32, 40, 48, 64, 256 - each size drawn on its own pixel grid).
icon.png           512 x 512, for the browser build.
Store/             Box art, poster art and hero art at both allowed sizes (opaque).
Source/            DoubleShift.svg - vector master (256 grid).
                   DoubleShift-16px.svg, DoubleShift-24px.svg - hand-tuned small sizes.
                   BoxArt.svg, PosterArt.svg, HeroArt.svg - Store art sources (text set in Geist).

Colours: #2563EB (upper bar), #60A5FA (lower bar).
Store background #F5F7FC, name #172033, tagline #5B6577.
